# تدبر (Tadabbur) — تطبيق ذكي لحفظ القرآن الكريم

تطبيق ويب (يعمل أيضًا كتطبيق PWA قابل للتثبيت) يساعدك على حفظ القرآن الكريم
باستخدام أساليب مبنية على أبحاث التعلّم بدلًا من إعادة القراءة السلبية.

## لماذا هو "ذكي"؟

1. **رحلة حفظ تدريجية موجّهة** — تبدأ تلقائيًا بسورة الفاتحة آيةً آية: تُخفى
   كلمات الآية تباعًا وتُعرض خيارات متعددة (أو خانة كتابة) لاختيار/كتابة
   الكلمة الناقصة. يجب إتمام 3 جولات صحيحة متتالية بلا خطأ لإتقان الآية قبل
   الانتقال للتي بعدها — ثم يتابع التطبيق تلقائيًا مع السور التالية.

2. **التكرار المتباعد (Spaced Repetition — خوارزمية SM-2)**
   بعد إتقان الآية تدخل جدول مراجعة مستقل يُحسب تلقائيًا حسب تقييمك لمدى
   تذكّرك لها. الآيات التي تتذكرها جيدًا تُراجَع على فترات أطول تدريجيًا،
   والصعبة تعود للمراجعة القريبة.

3. **اختبار صوتي بالنطق** — اقرأ الآية بصوتك، ويستمع التطبيق (Web Speech
   API) ويقارن كلماتك بالنص الصحيح كلمة كلمة، ويظهر لك الأخطاء بالتظليل
   ونسبة دقة التسميع.

4. **معاني الكلمات** — زر "معاني الكلمات" يعرض ترجمة كل كلمة في الآية
   (عبر quran.com) لمساعدتك على الحفظ بالفهم لا بالحفظ الآلي فقط.

5. **تحدي تعاهد يومي مفاجئ** — بطاقة على لوحتك تختار آيات عشوائية مما
   حفظته سابقًا لاختبار مفاجئ، تذكيرًا بحديث «تعاهدوا هذا القرآن...».

6. **تأثيرات وتشجيع مستمر** — قصاصات احتفالية (confetti)، أصوات نجاح/خطأ،
   رسائل تحفيزية عشوائية، وتصميم بطابع إسلامي (زخارف هندسية، أيقونة كتاب
   وهلال) لتشجيعك على الاستمرار يوميًا.

7. **لوحة متابعة** تعرض الآيات المستحقة اليوم، قيد الحفظ، المحفوظة، وسلسلة
   الأيام المتتالية (streak)، ونسبة التقدم في كل سورة.

## PWA — تثبيت كتطبيق

يحتوي المشروع على `manifest.json` و`sw.js` (service worker) فيمكن تثبيته
من المتصفح (Chrome/Edge: "تثبيت التطبيق" أو "إضافة إلى الشاشة الرئيسية")
ليعمل كتطبيق مستقل بأيقونة خاصة، مع تخزين مؤقت لملفات الواجهة للعمل بلا
اتصال جزئيًا.

## كيفية الاستخدام

التطبيق صفحة ويب ثابتة بالكامل (HTML/CSS/JS) بدون أي حزم أو بناء:

```bash
# من داخل مجلد المشروع
python3 -m http.server 8080
# ثم افتح http://localhost:8080 في المتصفح
```

أو يمكن رفعه مباشرة على أي استضافة ثابتة (GitHub Pages, Netlify, Vercel...).

يحتاج التطبيق اتصالًا بالإنترنت لجلب نص الآيات والتلاوة الصوتية من
[alquran.cloud](https://alquran.cloud) ومعاني الكلمات من
[quran.com](https://quran.com) (واجهتان برمجيتان مجانيتان بدون مفتاح API).
الاختبار الصوتي يستخدم Web Speech API المدمجة في المتصفح (متاحة حاليًا في
Chrome/Edge، ويُخفى الزر تلقائيًا في المتصفحات غير الداعمة). تقدّمك يُحفظ
بالكامل محليًا في متصفحك عبر `localStorage` — لا توجد قاعدة بيانات خارجية
ولا حساب مستخدم.

## خطوات الاستخدام المقترحة

1. من تبويب **"🌱 ابدأ الحفظ"**: تحفظ آيات سورة الفاتحة آيةً آية تفاعليًا
   (اختيار من متعدد أو كتابة)، مع إمكانية الاستماع ومعرفة معاني الكلمات.
2. بعد إتقان آية، تدخل تلقائيًا جدول المراجعة الظاهر في **"لوحتي"**.
3. من تبويب **"جلسة المراجعة"**: راجع المستحق يوميًا، واختبر نفسك بالنطق
   الصوتي أو بإخفاء الكلمات تدريجيًا، ثم قيّم مدى تذكرك.
4. جرّب **"تحدي تعاهد اليوم"** من لوحتك لاختبار مفاجئ لما حفظته سابقًا.
5. تبويب **"تصفح وإضافة"** متاح للمتقدمين لإضافة آيات مباشرة إلى جدول
   المراجعة دون المرور برحلة الحفظ التدريجية.

## هيكل المشروع

```
index.html      واجهة التطبيق (لوحتي / ابدأ الحفظ / تصفح وإضافة / جلسة المراجعة)
css/style.css   التنسيق (زخارف إسلامية، تأثيرات حركية، يدعم الوضع الليلي و RTL)
js/app.js       المنطق: SM-2، رحلة الحفظ التدريجية (MCQ/كتابة)، الاختبار
                الصوتي، معاني الكلمات، التحدي اليومي، الأصوات والاحتفالات
manifest.json   بيانات تطبيق الويب التقدمي (PWA)
sw.js           service worker لتخزين ملفات الواجهة مؤقتًا
icons/          أيقونات التطبيق بأحجام متعددة
```

## تطويرات مستقبلية ممكنة

- مزامنة التقدم عبر الأجهزة (حساب مستخدم + قاعدة بيانات).
- إشعارات يومية (push notifications) بتذكير المراجعات المستحقة.
- تحسين دقة المقارنة الصوتية بمحاذاة أكثر تسامحًا للأخطاء الطفيفة.
