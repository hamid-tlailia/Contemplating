# تدبر (Tadabbur) — تطبيق ذكي لحفظ القرآن الكريم

تطبيق ويب بسيط (بدون حاجة لخادم أو بناء) يساعدك على حفظ القرآن الكريم باستخدام
أساليب مبنية على أبحاث التعلّم بدلًا من إعادة القراءة السلبية:

## لماذا هو "ذكي"؟

1. **التكرار المتباعد (Spaced Repetition — خوارزمية SM-2)**
   كل آية تُحفظ لها موعد مراجعة مستقل يتم حسابه تلقائيًا حسب تقييمك لمدى
   تذكّرك لها (لم أتذكر / صعبة / جيدة / سهلة). الآيات التي تتذكرها جيدًا
   تُراجَع على فترات أطول تدريجيًا، والآيات الصعبة تعود للمراجعة القريبة —
   بدل جدول ثابت واحد للجميع.

2. **الاسترجاع الفعّال (Active Recall) بدل إعادة القراءة**
   في جلسة المراجعة تُخفى كلمات الآية تدريجيًا (إخفاء جزئي ثم كامل) بدلًا
   من قراءتها مكشوفة، لإجبار الدماغ على الاسترجاع الفعلي بدلًا من التعرّف
   البصري السطحي.

3. **الاستماع + القراءة معًا**
   كل آية مرتبطة بتلاوة صوتية (الشيخ العفاسي) لتعزيز الحفظ السمعي إلى جانب
   البصري.

4. **لوحة متابعة**
   تعرض عدد الآيات المستحقة اليوم، الآيات الجديدة، عدد الآيات "المتقنة"
   (بعد عدة مراجعات ناجحة بفواصل زمنية طويلة)، وسلسلة الأيام المتتالية
   (streak)، بالإضافة إلى نسبة التقدم في كل سورة.

## كيفية الاستخدام

التطبيق صفحة ويب ثابتة بالكامل (HTML/CSS/JS) بدون أي حزم أو بناء:

```bash
# من داخل مجلد المشروع
python3 -m http.server 8080
# ثم افتح http://localhost:8080 في المتصفح
```

أو يمكن رفعه مباشرة على أي استضافة ثابتة (GitHub Pages, Netlify, Vercel...).

يحتاج التطبيق اتصالًا بالإنترنت لجلب نص الآيات والتلاوة الصوتية من
[alquran.cloud](https://alquran.cloud) (واجهة برمجية مجانية بدون مفتاح API).
تقدّمك في الحفظ (الآيات المضافة، جدول المراجعة، السلسلة اليومية) يُحفظ
بالكامل محليًا في متصفحك عبر `localStorage` — لا توجد قاعدة بيانات خارجية
ولا حساب مستخدم.

## خطوات الاستخدام المقترحة

1. من تبويب **"تصفح وإضافة"**: اختر السورة ونطاق الآيات وأضفها إلى خطة الحفظ.
2. من تبويب **"جلسة المراجعة"**: استمع للآية، جرّب حفظها، أخفِ الكلمات
   تدريجيًا لاختبار نفسك، ثم قيّم مدى تذكرك — سيحدد التطبيق تلقائيًا موعد
   المراجعة القادمة.
3. تابع تقدمك من تبويب **"لوحتي"** يوميًا.

## هيكل المشروع

```
index.html      واجهة التطبيق (تبويبات: لوحتي / تصفح وإضافة / جلسة المراجعة)
css/style.css   التنسيق (يدعم الوضع الليلي تلقائيًا واتجاه RTL)
js/app.js       المنطق: جلب البيانات من الـ API، خوارزمية SM-2، إخفاء
                الكلمات التدريجي، إدارة الحالة في localStorage
```

## تطويرات مستقبلية ممكنة

- تسجيل صوت المستخدم ومقارنته بالتلاوة الأصلية (تصحيح النطق).
- مزامنة التقدم عبر الأجهزة (حساب مستخدم + قاعدة بيانات).
- دعم حفظ السور كاملة تلقائيًا (وليس فقط نطاقات آيات محددة).
- إشعارات يومية بتذكير المراجعات المستحقة.
